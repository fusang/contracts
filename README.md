# Fusang Contracts

Smart contracts for the Fusang trading platform. Two subprojects:

- [`swap/`](swap/) — a permissioned fork of Uniswap V3 with allowlist-based access control. See [`swap/README.md`](swap/README.md).
- [`token/`](token/) — `FSC20` regulated ERC-20 standard and `WalletList` access-control contract. See [`token/README.md`](token/README.md).

Each subproject has its own setup and tests.
