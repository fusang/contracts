# Fusang Swap

A permissioned fork of Uniswap V3 with allowlist-based access control. Intended for compliance-controlled trading environments.

## Local development

```bash
pnpm install
pnpm compile
pnpm test
```

Requires Node.js 22+ and `pnpm`.
